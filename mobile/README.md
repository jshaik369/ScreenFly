# Mobile Components

This directory contains the mobile application components for OmniScreen.

## Overview
The mobile version provides screen monitoring capabilities for iOS and Android devices with privacy-first design principles.

## Features
- Native mobile app development
- iOS and Android support
- Privacy-focused data handling
- Battery-efficient screen monitoring
- Cross-platform synchronization
