# ScreenFly

**Status: idea stage. There is no working code yet.**

ScreenFly is a planned tool for recording and reviewing activity on your own computer screen, so you can see how you spend time on your devices.

## Design principles

- **Your own device only.** It is not meant for watching another person.
- **Always visible.** A clear indicator shows whenever recording is on. There is no hidden or stealth mode.
- **Local by default.** Recordings stay on the device unless you choose to export them.
- **Easy to delete.** You can erase everything at any time.

Do not use any screen-recording tool to watch another person without their knowledge and consent. In many places, including the EU, that is illegal.

## Planned first version

A desktop app for Windows, macOS and Linux. Mobile may follow later.
