## Project Structure

ScreenFly is organized into the following components, each embodying our street photography philosophy for digital monitoring:

- **`/desktop`** - Desktop application for Windows, macOS, and Linux - capturing authentic desktop interactions
- **`/mobile`** - Mobile apps for iOS and Android - pocket-sized digital observation
- **`/browser`** - Browser extensions and web-based monitoring - web-native fly-on-the-wall perspective  
- **`/embedded`** - Embedded system implementations - monitoring at the hardware level
- **`/plugins`** - Plugin system and third-party integrations - extensible observation capabilities
- **`/docs`** - Project documentation (this directory) - comprehensive guidance and standards
