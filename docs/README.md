# Documentation

This directory contains all project documentation for OmniScreen.

## Project Structure

OmniScreen is organized into the following components:

- **`/desktop`** - Desktop application for Windows, macOS, and Linux
- **`/mobile`** - Mobile apps for iOS and Android
- **`/browser`** - Browser extensions and web-based monitoring
- **`/embedded`** - Embedded system implementations
- **`/plugins`** - Plugin system and third-party integrations
- **`/docs`** - Project documentation (this directory)

## Getting Started

1. Choose your platform component from the directories above
2. Follow the README in each directory for setup instructions
3. Contribute to the codebase following our privacy-first principles
