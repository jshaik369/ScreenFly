# Desktop Components

This directory contains the desktop application components for OmniScreen.

## Overview
The desktop version provides native screen monitoring capabilities across Windows, macOS, and Linux platforms with privacy-first architecture.

## Features
- Native desktop integration
- Cross-platform compatibility
- Privacy-focused data handling
- Real-time screen monitoring
